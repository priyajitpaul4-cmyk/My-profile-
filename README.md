# 🚀 Priyajit Paul — Portfolio

A clean, responsive personal portfolio website built with HTML5, CSS3, JavaScript, and Bootstrap 5. Showcases my skills, projects, and contact information in a modern single-page layout.

**🔗 Live Demo:** [https://priyajitpaul4-cmyk.github.io/My-profile-/](https://priyajitpaul4-cmyk.github.io/My-profile-/)

---

## 📸 Preview

| Section | Description |
|---|---|
| 🏠 Home | Animated hero banner with intro and CTA buttons |
| 👤 About | Bio and core skill badges |
| 💼 Projects | Dynamic project cards (rendered via JS) |
| 🛠 Skills | Categorized technical & soft skills |
| ✉️ Contact | Validated contact form + social links |

---

## ✨ Features

- Fully responsive layout (mobile, tablet, desktop)
- Sticky navigation bar with smooth scrolling
- Bootstrap 5 grid & components
- Font Awesome icons throughout
- Client-side form validation
- Projects section populated dynamically via JavaScript

---

## 🧰 Tech Stack

- **HTML5** — semantic structure
- **CSS3** — custom styling (`styles.css`)
- **JavaScript** — interactivity & dynamic content (`script.js`)
- **Bootstrap 5** — responsive grid & UI components
- **Font Awesome** — icon library

---

## 📁 Project Structure

```
My-profile--main/
├── index.html      # Main page markup
├── styles.css      # Custom styles
└── script.js       # Dynamic behavior (projects, form handling, etc.)
```

---

## 🖥️ Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/priyajitpaul4-cmyk/My-profile-.git

# Navigate into the project
cd My-profile-

# Open index.html in your browser
```

No build tools or dependencies required — it's a static site that runs directly in the browser.
